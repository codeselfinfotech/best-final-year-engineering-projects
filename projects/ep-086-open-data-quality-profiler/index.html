EP-086 · Industrial Automation

Open Data Quality Profiler

This project investigates open data quality profiler through a scoped industrial automation prototype, measurable evaluation, and a student-friendly implementation path.

DepartmentECE
DifficultyIntermediate
Technology stackPLC concepts, Python, MQTT

Problem statement

Current workflows make it difficult to observe, measure, or improve open data quality profiler consistently.

Proposed solution

The proposed system collects appropriate inputs, processes them with PLC concepts, and presents an explainable result to its intended user.

Key features

  • Clear user workflow
  • Validation and review step
  • Searchable or measurable output
  • Documented limitations

Modules

  • Requirements and data model
  • Core prototype
  • Validation dashboard
  • Documentation and demo

Implementation approach

Start with a small validated dataset or hardware setup, build the core workflow, compare it with a baseline, and document accuracy, latency, usability, or resource use.

Expected output

Working prototype, sample dataset or hardware demo, architecture diagram, test evidence, and final presentation for open data quality profiler.

Future enhancements: Future work can add richer integrations, stronger security, broader validation, and production deployment safeguards.
