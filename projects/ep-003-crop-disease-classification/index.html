EP-003 · IoT & Embedded

Crop Disease Classification

This project investigates crop disease classification through a scoped iot & embedded prototype, measurable evaluation, and a student-friendly implementation path.

DepartmentECE
DifficultyAdvanced
Technology stackESP32, MQTT, Python

Problem statement

Current workflows make it difficult to observe, measure, or improve crop disease classification consistently.

Proposed solution

The proposed system collects appropriate inputs, processes them with ESP32, and presents an explainable result to its intended user.

Key features

  • Clear user workflow
  • Validation and review step
  • Searchable or measurable output
  • Documented limitations

Modules

  • Requirements and data model
  • Core prototype
  • Validation dashboard
  • Documentation and demo

Implementation approach

Start with a small validated dataset or hardware setup, build the core workflow, compare it with a baseline, and document accuracy, latency, usability, or resource use.

Expected output

Working prototype, sample dataset or hardware demo, architecture diagram, test evidence, and final presentation for crop disease classification.

Future enhancements: Future work can add richer integrations, stronger security, broader validation, and production deployment safeguards.
