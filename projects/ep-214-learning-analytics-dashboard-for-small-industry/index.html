EP-214 · Healthcare Technology

Learning Analytics Dashboard for Small Industry

This project investigates learning analytics dashboard for small industry through a scoped healthcare technology prototype, measurable evaluation, and a student-friendly implementation path.

DepartmentCSE
DifficultyBeginner
Technology stackPython, FastAPI, FHIR

Problem statement

Current workflows make it difficult to observe, measure, or improve learning analytics dashboard for small industry consistently.

Proposed solution

The proposed system collects appropriate inputs, processes them with Python, and presents an explainable result to its intended user.

Key features

  • Clear user workflow
  • Validation and review step
  • Searchable or measurable output
  • Documented limitations

Modules

  • Requirements and data model
  • Core prototype
  • Validation dashboard
  • Documentation and demo

Implementation approach

Start with a small validated dataset or hardware setup, build the core workflow, compare it with a baseline, and document accuracy, latency, usability, or resource use.

Expected output

Working prototype, sample dataset or hardware demo, architecture diagram, test evidence, and final presentation for learning analytics dashboard for small industry.

Future enhancements: Future work can add richer integrations, stronger security, broader validation, and production deployment safeguards.
